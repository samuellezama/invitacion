# Recursos de Imágenes - Iglesia sin Fondo

## Cómo obtener una imagen de iglesia en PNG (sin fondo)

### Opción 1: Usar Generadores de IA
- **DALL-E** (https://openai.com/dall-e)
  - Prompt sugerido: "Church building illustration, transparent background, PNG format, no background"
  
- **Midjourney** (https://www.midjourney.com)
  - Prompt: "church building isolated on transparent background, PNG --no-background"
  
- **Bing Image Creator** (https://www.bing.com/images/create)
  - Prompt: "iglesia, sin fondo, formato PNG, ilustración"

### Opción 2: Descargar de Bancos de Imágenes Gratuitos
- **Pixabay** (https://pixabay.com)
  - Buscar: "church transparent" o "iglesia PNG"
  
- **Pexels** (https://www.pexels.com)
  - Buscar: "church building"
  
- **Unsplash** (https://unsplash.com)
  - Buscar: "church architecture"
  
- **Freepik** (https://www.freepik.com)
  - Buscar: "iglesia PNG" o "church PNG"

### Opción 3: Remover Fondo Automáticamente
Si ya tienes una imagen de iglesia, puedes remover el fondo con:

- **Remove.bg** (https://www.remove.bg)
  - Sube la imagen y descárgala en PNG
  
- **Photoshop** (herramienta de selección por objeto)
  
- **GIMP** (gratuito)
  - Usa la herramienta "Select by Color" o "Fuzzy Select"
  - Elimina el fondo
  - Exporta como PNG

### Opción 4: Usar Iconos/Ilustraciones de Iglesia
- **Flaticon** (https://www.flaticon.com)
  - Buscar: "church icon" - muchas opciones con fondo transparente
  
- **Icons8** (https://icons8.com)
  - Búsqueda: "church" - descargar en PNG

## Pasos Recomendados

1. Elige la opción que mejor se adapte a tu necesidad
2. Descarga o genera la imagen
3. Asegúrate de que esté en formato **PNG** (soporte para transparencia)
4. Guarda la imagen en la carpeta `/assets/images/` del proyecto
5. Usa la imagen en tu proyecto de invitación

## Estructura Sugerida
```
invitacion/
├── assets/
│   └── images/
│       └── iglesia.png
├── index.html
└── styles.css
```

## Nota
Para mejores resultados con IA, especifica en tu prompt:
- "transparent background" o "sin fondo"
- "PNG format"
- El estilo deseado: "illustration", "photo", "cartoon", etc.
- El tamaño aproximado: "square", "portrait", etc.
